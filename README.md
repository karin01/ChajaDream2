# 반려동물 차자드림

## 프로젝트 소개
반려동물 실종/발견/제보를 위한 MZ 감성의 웹 서비스입니다. 
- 실종/발견 동물 게시판, 사진/정보 등록, 상세 모달, 성공사례, 팁 등 제공
- 프론트엔드(Tailwind+JS) + 백엔드(Flask API) 구조

## 폴더 구조
- `index.html` : 메인 페이지 (게시판, 등록 폼, 성공사례 등)
- `js/` : 프론트엔드 JS (동물 등록/목록/모달 등)
- `css/` : 커스텀 스타일 (카드, 버튼, 모달 등)
- `backend/` : 백엔드(Flask) API 서버

## 프론트엔드 실행법
1. `index.html`을 브라우저에서 열면 바로 사용 가능
2. 게시물 등록/목록/상세 모달 등 JS로 동작

## 백엔드 실행법
1. `backend/` 폴더에서 아래 명령어 실행
   ```bash
   pip install -r requirements.txt
   python app.py
   ```
2. 기본 포트: 8765 (`서버실행.bat`의 `PORT`, http://localhost:8765). 포트 충돌 시 배치에서 숫자만 바꾸면 됨.
3. API 예시:
   - `GET /api/posts` : 게시물 목록 조회
   - `POST /api/posts` : 게시물 등록

## 주요 기능
- 실종/발견 동물 게시판 (사진, 정보, 연락처 등)
- 카드형 목록, 썸네일, 상세 모달(팝업)
- 성공사례, 보호 팁, MZ 감성 디자인
- (백엔드) REST API로 게시물 관리
